## 2. 專題題目
**線上德州撲克多人對戰與策略分析平台**

## 3. 專題內容簡介
本專題旨在開發一套兼具「即時競技」與「牌局數據分析」的線上德州撲克平台。除了提供玩家流暢的多人線上對戰體驗外，系統還會記錄並分析玩家的下注習慣與歷史牌局，幫助玩家提升遊戲策略與技術。

* **主要功能**：
  1. **玩家端（對戰與大廳）**：
     * **房間與匹配系統**：支援建立私人房（密碼房）與隨機匹配快速對戰。
     * **即時對戰介面**：包含洗牌發牌、計時下注（盲注/加注/棄牌/跟注）、籌碼結算與動畫效果。
  2. **策略與數據分析端**：
     * **歷史牌局回放（Hand Replay）**：完整記錄每輪牌局流程，方便檢討決策。
     * **戰績與數據統計**：統計玩家勝率、入局率 (VPIP)、加注率 (PFR) 等專業撲克指標。
  3. **管理員端**：
     * **帳號與籌碼管理**：使用者權限管控、每日登入獎勵發放與異常行為檢測。
